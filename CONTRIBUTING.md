# Contributing to CronCraft

Thank you for contributing to **CronCraft**!

## Development Setup

1. Clone and build:
   ```bash
   npm run build
   ```
2. Run test suites:
   ```bash
   npm test
   ```
3. Submit a Pull Request following Conventional Commits (`feat:`, `fix:`, `docs:`).
