# Changelog — CronCraft

## [1.0.0] - 2026-11-18
### Added
- Core 5-field and 6-field cron parser with presets and text aliases.
- Plain English explanation and natural language query translation.
- Multi-timezone execution matrix (UTC, EST, PST, GMT, IST, JST).
- Multi-job collision and resource contention auditor.
- Embedded Bento Grid Web Studio on port 6464.
- CLI interface and native test runner coverage.
