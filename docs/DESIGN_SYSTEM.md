# CronCraft Master Design System

Aesthetics integrated from the **29 Master Design Patterns Catalog**:

1. **Bento Grid (#12):** Asymmetric, responsive card layout categorizing expression inputs, timezone tables, density charts, and crontab linters.
2. **Dark Mode UI (#20):** Deep obsidian `#07090e` base with frosted translucent cards.
3. **Cybercore (#24):** Electric cyan `#38bdf8`, neon violet `#a855f7`, and monospace metrics.
4. **Swiss Design (#3):** Typographic hierarchy pairing **Plus Jakarta Sans** with **JetBrains Mono**.
5. **Glassmorphism (#10) & Neumorphism (#8):** Translucent backdrop blurs with subtle borders and inset glows.
