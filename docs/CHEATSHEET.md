# CronCraft CLI Cheatsheet

| Command | Description |
| :--- | :--- |
| `croncraft next "<expr>"` | Calculate next 5 run occurrences |
| `croncraft next "<expr>" -n 10` | Calculate next 10 run occurrences |
| `croncraft explain "<expr>"` | Translate cron into natural English |
| `croncraft natural "<query>"` | Convert natural English to cron |
| `croncraft audit <crontab>` | Detect schedule collisions in crontab |
| `croncraft studio` | Launch Web Studio on port 6464 |
