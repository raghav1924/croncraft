# Bento Grid Studio User Guide (Port 6464)

Launch the interactive Web Studio:
```bash
croncraft studio --port 6464
```
Navigate to `http://localhost:6464`.

## Features
- **Live Expression Linter:** Type or click preset pills (`@daily`, `@weekly`, `*/15 * * * *`) for instant feedback.
- **Natural Language Builder:** Enter plain English ("every weekday at 2:30am") to generate cron syntax.
- **Multi-Timezone Table:** Live synchronized run times across 6 major global zones.
- **24-Hour Execution Density Waterfall:** Dynamic SVG histogram visualizing task load by hour.
- **Collision Radar:** Automated contention risk score (0-100%) and staggering recommendations.
